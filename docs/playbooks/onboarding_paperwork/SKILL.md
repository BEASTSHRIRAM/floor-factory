# Complete onboarding paperwork for this week's joiners

Job family `onboarding_paperwork` · department `hr` · tool server `hrdesk` · budget ₡130.

## When to Use

Work through each joiner's onboarding checklist and complete every outstanding step on their required-documents list. Do not complete steps that are not on the required list.

## Procedure

1. List the onboarding cases with incomplete steps.
2. Complete each outstanding paperwork step.
3. Confirm no onboarding step remains incomplete.

## Pitfalls

- The Reviewer rejects the job when this does not hold: For every joiner, the set of completed onboarding steps equals exactly the joiner's required-documents list

## Verification

The Reviewer runs deterministic checks against live workplace state — one finding per acceptance criterion below; a failed check is an automatic reject, and the failed findings become the worker's next lesson.

- For every joiner, the set of completed onboarding steps equals exactly the joiner's required-documents list
